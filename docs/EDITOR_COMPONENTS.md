# Tmod editor components

Tmod keeps its Termux terminal, sessions, bootstrap and package repository. The integrated project editor uses:

- [sora-editor](https://github.com/Rosemoe/sora-editor) 0.24.7, GNU LGPL 2.1 or later.
- [monarch-kt language pack](https://github.com/dingyi222666/monarch-kt) 1.0.2, Apache License 2.0.

The libraries are linked from Maven at build time. Their source and license text are available from the linked upstream repositories.
